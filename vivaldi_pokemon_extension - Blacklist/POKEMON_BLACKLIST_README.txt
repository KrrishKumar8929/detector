Pokemon Detector - Skip List feature

Open the extension popup and use the 'Pokemon to Skip' box. Enter one name per line (commas and semicolons are also accepted), then click Save skip list.

If a detected Pokemon matches the list, the extension output and copy action are exactly one dot: .
Other Pokemon keep the existing output behavior. Names are compared case-insensitively and accent/punctuation normalized.

Install: extract this ZIP to a folder, then open vivaldi://extensions, enable Developer mode, click Load unpacked, and select the extracted folder. Back up your current extension folder first.
